# Элегант: первая версия учёта магазина

Браузерная версия для проверки рабочих сценариев. Это не готовая многопользовательская серверная CRM.

## Запуск

`npm run dev`, затем открыть http://localhost:8080. Проверки модели: `npm test`.

## Что работает

- Каталог: артикул, название, категория, вариант, остаток, закупочная, оптовая и розничная цены.
- Начальные остатки, новые закупки, приёмка с распределением доставки в среднюю стоимость.
- Продажи по одной позиции, оптовые условия клиента, частичная оплата и долги.
- Полный возврат с восстановлением склада и исключением продажи из выручки.
- Клиенты, история покупок и движения товара.
- Отчёты с фильтром периода, CSV каталога, резервная копия и восстановление JSON.
- Напоминание о закупке после продажи 30% запаса (порог настраивается). База порога обновляется при приёмке. Товары в пути не дублируются в рекомендациях.

## Хранение и ограничения

Демо и свой учёт используют разные ключи localStorage. Данные остаются в конкретном браузере на конкретном домене, не отправляются на сервер и не синхронизируются между устройствами. Смена домена, локального порта или браузера требует переноса через резервную копию. Очистка хранилища удаляет данные. Не использовать как единственную систему хранения реальных финансовых данных.

Одна продажа и одна закупка содержат одну товарную позицию. Все суммы в рублях, внутри модели в копейках. Закупка считается полностью оплаченной при заказе; доставка при получении. Возврат полный. Себестоимость продажи фиксируется при проведении; отчёт показывает валовую прибыль, не чистую. Расходы, касса, налоги, валютные закупки, отмена поставок и частичные возвраты пока не реализованы. Входа, серверной БД и автоматических бэкапов нет.

Перед рабочим запуском: серверная БД, авторизация, права доступа, резервное копирование и проверка восстановления. GitHub Pages подходит только для этой браузерной демонстрационной версии.

Шрифт Golos Text загружен с Google Fonts и хранится локально. Финальный фирменный логотип ещё не выбран, в интерфейсе используется текстовое название.

## Напоминания, аналитика и звук

Добавлены автоматические напоминания о закупках, поставках в ближайшие три дня и неоплаченных продажах. Срок оплаты долга не выдумывается: задолженность не называется просроченной без установленного срока. Можно создать свою задачу с датой и временем и отметить выполненной. Задачи входят в JSON-копию; старые резервные копии без задач по-прежнему поддерживаются.

Проверка напоминаний выполняется раз в минуту при видимой странице и при возвращении во вкладку. Это не системные push-уведомления: в закрытом браузере они не работают. Звук отключён по умолчанию и включается кнопкой динамика. Сигналы синтезируются локально, аудиофайлы и внешние сервисы не используются. После перезагрузки браузеру может потребоваться взаимодействие с пользователем для разрешения звука.

Аналитика: средняя сумма одной продажи, валовая маржа, выручка за последние 14 дней выбранного периода, пять товаров по выручке и распределение по каналам. Одна продажа пока содержит одну позицию, поэтому метрика не называется средним чеком. Анимация панелей и уведомлений поддерживает reduced motion; клавиатурное открытие панели мгновенное.

## Визуальный каталог

Главный экран по выбранному макету «Магазин на ладони»: категории с иллюстрациями, количество товаров и подсказки о закупке, справа товары с тремя ценами и действиями. Кнопка «Таблица» возвращает общий список, фильтры и CSV. Поиск в визуальном режиме ищет по всему ассортименту. Изображения категорий сгенерированы для интерфейса и не представляют реальные товары магазина. Логотип по-прежнему не утверждён.
